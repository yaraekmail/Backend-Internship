# Week 2 - Day 2
## LINQ: Grouping, Joining & Flattening

### 📚 Learning Objectives
- Understand deferred and immediate execution in LINQ.
- Group data using `GroupBy`.
- Combine related collections using `Join`.
- Flatten nested collections using `SelectMany`.
- Understand common LINQ performance considerations.

---

## 🛠️ Project

**AlMandoob Stone Management System**

This project simulates a stone and marble management system and applies LINQ concepts using real business entities instead of simple examples.

---

## 📂 Models Used

- Customer
- Employee
- Project
- Service
- Stone
- StoneType
- Supplier

---

## ✅ Tasks Implemented

### 1. GroupBy
Grouped projects by customer and calculated the total project value for each customer.

### 2. Join
Joined customers with projects to display customer names alongside project information.

### 3. SelectMany
Flattened project services into a single sequence using `SelectMany`.

### 4. Deferred vs Immediate Execution
Demonstrated the difference between deferred execution and immediate execution using `Where()` and `ToList()`.
