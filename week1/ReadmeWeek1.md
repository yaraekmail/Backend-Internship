
# Week 1 — C# Fundamentals & Git Workflow

> Backend Internship — Week 1
> Focus: C# fundamentals, Object-Oriented Programming, Collections, LINQ, Async/Await, Exception Handling, and Git/GitHub workflow.

---

## 📌 Overview

Week 1 focused on building the fundamental C# and .NET skills required for backend development.

Throughout the week, I practiced creating and running .NET console applications, working with C# types and control flow, applying Object-Oriented Programming concepts, using collections and LINQ, writing asynchronous code, handling exceptions, and learning the Git/GitHub workflow.

The practical work was organized into five days, with each day building on the concepts introduced previously.

### Day 2 — C# Fundamentals I: Types, Variables & Control Flow

Day 2 focused on understanding C# types, variables, control flow, and nullable reference types.

Topics practiced:

* Value Types vs Reference Types
* Variables and type inference
* Naming conventions
* `GetType()`
* `if` statements
* `switch` expressions
* Value vs Reference copy behavior
* Nullable Reference Types

Hands-on tasks included:

* Creating value-type and reference-type variables
* Demonstrating value/reference copy behavior
* Creating a grade classifier using a switch expression
* Safely handling nullable user input

### Day 3 — C# Fundamentals II: Object-Oriented Programming

Day 3 focused on the main Object-Oriented Programming concepts in C#.

Topics practiced:

* Classes
* Records
* Structs
* Encapsulation
* Access Modifiers
* Inheritance

* Polymorphism

The practical work used a small **Library Management System** domain containing classes such as:

### Day 4 — C# Fundamentals III: Collections & LINQ Basics

Day 4 focused on working with collections, querying data using LINQ, asynchronous programming, and exception handling.

* BitArray
* LINQ
* Query Syntax

* `Select()`

* `Task.Delay()`
* Exception Handling
